# Акула Мила находит друзей — видео-сказка

Скрипт `make_video.py` собирает из фотографий страниц книги MP4-видео:

- плавное движение камеры по иллюстрациям и переходы между разворотами;
- женская озвучка на русском (RHVoice, голос «victoria»);
- субтитры с текстом сказки;
- тихая фоновая «подводная» музыка;
- титульный кадр (обложка) и финальный кадр «Конец».

## Запуск

```bash
sudo apt-get install -y ffmpeg rhvoice rhvoice-russian
pip install pillow numpy
# в папке pages/: 0.jpg — обложка, 1.jpg … 5.jpg — развороты по порядку
python3 make_video.py pages akula_mila.mp4
```

Результат: 1920×1080, 25 кадров/с, около 2 минут.

Фотографии книги и готовое видео в репозиторий не добавлены: иллюстрации и текст
принадлежат издательству «Проф-Пресс».
